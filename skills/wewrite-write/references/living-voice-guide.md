# 活人感写作指南（Living Voice）

> 融合自 数字生命卡兹克《khazix-writer》与《human-writing》（活人感写作）开源方法论。
> 适用：个人号、学习记录号、AI 博主。目标是让读者觉得"对面有一个具体的人"——
> 知道一些事，也有不知道的地方，愿意讲细节，敢下判断，偶尔岔开一句还能接回来。

## 0. 核心信条

1. **活人感首先来自材料，其次来自说话位置，最后才是语气。** 没有真实材料的口语化只是"论坛服装"。
2. **真诚是唯一的捷径。** 可以不写，但绝不骗人；不懂就大方承认。
3. **AI 是扩写器，不是你的大脑。** 核心观点、真实经历、情绪节点必须来自用户；AI 负责找证据、找类比、按定好的角度扩写。
4. **读者要的是"我替你做了这件事"，不是"我给你科普这件事"。**

## 1. 动笔前：材料门槛（必须先过）

非虚构稿计划 1200 字以上时，先逐条写出**至少 5 件具体材料**，并注明来自用户哪句话或哪份来源。只写概括性类别不算（"用户喜欢 AI 工具"不算材料）。

**不能撑篇幅的**：同一观点换说法、抽象意义推演、比喻、无来源的典型场景、模型临时想的"比如有个人"。

材料不足时三选一：
- 事实型题目 → 先研究（有检索工具却不用，仍然算没有材料）
- 个人体验型 → 一次问完最多 3 个问题（"你和这件事实际发生过什么关系？哪个瞬间/数字/动作最让你在意？你现在最想说的判断是什么？"）
- 用户不让问且研究后仍不足 → 缩小题目，最多交 600 字短答。**宁可短，不注水。**

## 2. 说话位置（动笔前在内部回答，不交给用户）

1. 谁在说这件事，他凭什么知道，哪里只是推测。
2. 什么事情让他现在想说（一条新闻、一次经历、一个一直想不通的小事）。
3. 手里有哪些能托住文章的东西（动作、数字、时间、地点、原话、失败、代价、后来结果）。
4. 他对哪一点有明确判断，依据是什么，到哪里为止。
5. 读者读完上一段后，最自然会追问什么——下一段就接这个。

## 3. 写作机制（重点，逐条执行）

### 3.1 推进：每段必须带来新东西
新事实、新动作、新例子、新区别或新后果，五者至少其一。**同一观点改换说法不算推进。** 后一段接住前一段留下的问题，不靠"更深一层""真正的问题"这类路标。

### 3.2 节奏
- 长短句交替；连续 3 句同长 = 节奏呆板。
- 一句话独立成段，只在需要停顿的重点位置（全文 3 次左右）。
- 每次偏离主线后加**扣主线句**，一句就够，高频出现，把读者拉回来。
- 疑问句做刹车和转向（"为啥复制一遍会有效果呢？"）。

### 3.3 论述中的故意打破
重复强调（"就是……就是……单纯的想看看"）、中途打断（"我当时就……"）、省略主语（"想看看"而非"想要了解一下"）、刻意模糊（"我就不说是谁了"）。这些不是错误，是像真人的关键。

### 3.4 知识输出方式
"聊着聊着顺手掏出来"，不是"下面我来科普一下"。引用论文/历史要像"聊着聊着想起来的"，不是"我特意去查的"。

### 3.5 体感记忆代替知识性描述
"我当时就愣住了"（体感记忆）✓ / "我当时很震撼"（知识性描述）✗。
动作、细节、原话已经把感情写出来就停，不追着替读者解释。

### 3.6 判断力与对立面
- 敢下判断，有明确好恶，但姿态是"我被打动了/我觉得他说的是事实"，不是居高临下。
- 讲观点前先站在对方角度把处境具体化（"你就是一个普通上班族，不写代码也不需要天天写文章"），承认这种处境合理，再切入自己的视角。

### 3.7 谦逊铺垫法
给观点/建议前先用自谦卸掉防御："我也不知道行不行""我自己也有一些不成熟的经验"。尤其在教程类长文开头和结尾。

### 3.8 文化升维
聊完具体事情后，自然连接到更大的文化/哲学/历史参照物（从"淘宝卖DeepSeek"联想到"北京折叠"）。不是硬凑升华，是"聊着聊着自然想到了"。**禁止结尾强装升华和重新摘要全文。**

### 3.9 回环呼应（契诃夫之枪）
开头埋的意象/句子/小钩子，后面以变体形式再次出现。前后因果闭合，文章才从"信息流"变成"作品"。

### 3.10 人物画像法
从一个数据点出发，3-5 句让一个人物立体：触发点数据 → 快速代入 → 多维堆砌（城市→职位→生活→心理→具体行为）→ 情感锚定 → 细节具象化。

### 3.11 具体名字
不说"AI工具""某个模型"，说 Claude Code、豆包、即梦、DeepSeek。空泛工具名是 AI 味标记。

## 4. 文章原型（写前先判断属于哪种）

| 原型 | 核心 | 写法重心 |
|---|---|---|
| 调查实验型 | 我替你去做了这件事 | 过程叙事 + 发现层层递进 |
| 产品体验型 | 跟我一起玩 | 场景演示 + 真实感受 |
| 现象解读型 | 你注意到了吗？背后是什么 | 观察→好奇→研究→升维 |
| 工具分享型 | 我发现了一个好东西 | 个人故事铺垫→展示→效果惊艳 |
| 方法论分享型 | 我把压箱底的掏给你 | 每节落到可执行动作 + 坦诚学习成本和失败点 + 谦逊铺垫 |

## 5. 开头必杀技（选一）

- 叙事启动："故事是这样的。"
- 荒诞事实：抛一个让人"？？？"的事实
- 热点破题："这两天被xx刷屏了。"
- 好奇心驱动："这两天刷到一张图，很有意思。"

**永远从一个具体的、当下的事件/场景切入。** 禁止"在当今AI快速发展的时代""随着技术的不断进步"。

## 6. 四层自检（初稿完成后执行）

写完先跑 `scripts/check_prose.py <稿件路径>`，硬禁令清零后过下面四层：

### L1 硬性规则（脚本扫描）
禁用词、禁用标点（：——""）、结构套话、空泛工具名。**零命中。**

### L2 风格一致性
- 开头从具体场景切入？第一句让人"然后呢？"
- 长短句交替？有 3 次以上单句成段？
- 口语化词组 8-10 个？有自嘲或承认不足？标点在表达情绪？
- 不加小标题、不大量加粗？（分条目的方法论文章除外）

### L3 内容质量
- 每个核心观点有具体的人/场景/细节/数据支撑？有没有空泛论断？
- 知识是"聊着聊着掏出来"的吗？有没有"下面我来介绍"？
- 至少一处自然的文化升维？
- 有没有先理解对方处境再给观点？
- 类型专项：按第 4 节原型检查（调查型有亲自下场的叙事感？方法论型每节可执行？）

### L4 活人感终审（最重要，最主观）
以读者视角通读全文，回答一个问题：
**"读完这篇文章，我感觉是一个有见识的普通人在认真跟我聊一件打动他的事，还是一个 AI 在给我输出信息？"**

- 温度感：情绪是体感记忆还是知识性描述？
- 独特性：换个 AI 博主能写出差不多的东西吗？
- 姿态：有没有滑入"导师教学生"或"品牌做营销"？
- 心流：有没有哪个地方注意力断掉、需要回头理顺逻辑？

L4 不通过没有机械修法：把 AI 味重的段落找出来，想象作者本人会怎么说，用更口语、更私人、更不完美的说法重写。

## 7. 协作流程（重要）

```
用户：提供素材 + 核心观点 + 个人经历 + 情绪节点
  ↓
AI：补背景知识 + 找证据类比 + 结构建议 + 按角度扩写
  ↓
用户：二次改写（加入自己的声音、打破节奏、补真实细节）
  ↓
AI：四层自检 → 输出修改建议
  ↓
用户：终审定稿
```

**禁止**：素材不足时 AI 自作主张编造经历/场景/案例来"完成"文章。宁可输出更短、更实的稿子。

## 8. 交稿

只交作品，不展示内部提纲和检查过程。事实稿在文末列出对结论重要的少数来源；个人经历和观点稿不附。不建立作者画像，不把检索笔记塞进正文。
